# Data access

This repository shares construction code. It does not redistribute the original inputs, internal
CFPS decile summaries or final household-group data products.

## Original inputs

Acquire the 2023 national input-output table and non-financial flow-of-funds accounts from the
National Bureau of Statistics, financial accounts from the People's Bank of China, and the CFPS
2022 family economics file through the Institute of Social Science Survey, Peking University.
Exact expected filenames, input layouts and provider links are in [inputs/README.md](inputs/README.md).
Follow each provider's terms; CFPS registration and acceptance of the user agreement are required.

## Final SAM and group outputs

The full income-decile matrix, household-related validation, sensitivity and multiplier outputs
are being prepared for a deposit arrangement to be confirmed with the CFPS team. The proposed
route is the CFPS data centre or Peking University Open Research Data platform. Platform acceptance,
permitted file scope, reader and reviewer access, and data licences are not yet confirmed.

When those arrangements are complete, this page will link to the actual dataset record. Access to
code alone should not be read as evidence that the dataset is already deposited or accessible.

Official CFPS guidance:
https://www.isss.pku.edu.cn/cfps/en/faq/PublishwithCFPSData/index.htm

## Files excluded from Git

The default ignore rules exclude all files other than the approved source and documentation list.
In particular, original input files, `.dta`/`.sav` files, archives, local credentials, `intermediate/`,
`output/`, `figures/`, manuscript files and local logs are not tracked. A file being generated by
this code does not establish a right to share it.
